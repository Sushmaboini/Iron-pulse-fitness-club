# Iron Pulse Fitness Club

A beginner-friendly fitness club website built using HTML to practice and demonstrate core HTML concepts.

## 🌐 Live Demo

[View Live Website](https://sushmaboini.github.io/Iron-pulse-fitness-club/)

## 📌 About the Project

Iron Pulse Fitness Club is a static fitness club website created as part of my HTML learning journey.

The project focuses on building a complete webpage using HTML without relying on CSS or JavaScript.

## 🛠️ Technologies Used

- HTML5

## 📚 HTML Concepts Practiced

- HTML document structure
- Headings and paragraphs
- Text formatting
- Lists
- Hyperlinks
- Tables
- Forms
- Audio
- Video
- HTML attributes
- Semantic structure

## ✨ Features

- Fitness club information
- Navigation links
- Fitness-related sections
- Membership/contact form
- Tables for structured information
- Multimedia content
- Contact section

## 🎯 Purpose

This project was created to strengthen my understanding of HTML and practice building a complete webpage from scratch.

It is one of my first projects in my journey toward becoming a software developer.

- Add JavaScript for form validation and interactions
